## Research approach

- **Make assumptions visible.** Model boundaries and source context accompany the code.
- **Check what can be checked.** Exhaustive small cases, causal-prefix tests and numeric constraints support the implementations.
- **Keep examples reproducible.** Public-data and synthetic demos can be explored without employer files.

The repositories include independent research, coursework-derived implementations
and contributions to collaborative workflows. Each project describes its provenance,
what was verified and what still depends on external data or longer training runs.

**Tools:** Python · NumPy · SciPy · pandas · PyTorch · scikit-learn · Streamlit
